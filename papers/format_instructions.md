# ACM Formatting Instructions for Agent Execution

The following instructions define the layout and workflow requirements based on the "interim-layout (1).pdf" document.[cite: 1]

## 1. Document Setup & Hierarchy
* **Initial Mode:** Set the document to "Draft" mode during initial content entry.
* **Heading Structure:** 
    * Use "Insert Heading Level 1" for primary sections.
    * Use "1.1 Heading Level 2" for subsections.
    * Use "1.1.1 Heading Level 3" for sub-subsections.
    * Use "1.1.1.1 Heading Level 4" for the lowest level.
* **Special Sections:** Place CCS CONCEPTS, KEYWORDS, and ACM Reference Format metadata before the first heading.

## 2. Mathematical Content & Styling
* **Numbered Equations:** 
    * Apply "Display Formula" style.
    * Equation numbers must be aligned to the right.
    * Any paragraph immediately following a numbered equation must be styled as "ParaContinue".
* **Unnumbered Equations:** Apply "DisplayFormulaUnnum" style.
* **Math Statements:** Use specific blocks for Theorem, Proof, or Lemma as structured enunciations.

## 3. Reference & Cross-Linking Workflow
* **Reference Numbering:** Place the cursor at the start of the reference list and execute "Reference Numbering" from the "Reference Elements" menu.
* **Cross-Linking:** After reference marking, run all options under the "Cross Linking" menu to link float elements and bibliography citations.
* **Validation:** Run "Manuscript Validation" to identify missing metadata or styling errors; correct these and rerun until successful.

## 4. Metadata & Template Application
* **Template Selection:** Use the "Define Template Style" function and choose between "Journals" or "Proceedings".
* **Required Input:** You must provide specific values when prompted: Acronym, DOI, ISBN, Copyright text, and Year.
* **Footnotes:** 
    * Article Title Footnotes must be captured as "Title Note".
    * Author Footnotes must be captured as "Author Note".

## 5. Visual Elements & Accessibility
* **Figures:** Place the image above the caption.
* **Alt-Txt Requirements:** 
    1. Right-click the image and select "Format Picture".
    2. Navigate to "Layout & Properties" (icon 3) and expand "Alt Txt".
    3. Fill both "Title" and "Description" text boxes.

## 6. Finalization
* **Submission Elements:** Ensure the inclusion of Fundref data and Document History (for journals).
* **PDF Export:** Use the "Save as PDF" option only after the final template layout has been applied and validated.
